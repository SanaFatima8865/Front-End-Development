# Patient Dashboard - React Application

A pixel-perfect implementation of a healthcare patient dashboard based on Adobe XD design, with API integration for patient data.

## Features

- Pixel-perfect design implementation
- API integration with Basic Authentication
- Responsive design for all screen sizes
- Interactive blood pressure chart using Chart.js
- Display of Jessica Taylor's patient data only
- Clean, modular React component architecture
